🔧 Quick Test - Simpan Pelanggaran

Instruksi:

  1. Pastikan sudah login sebagai guru di tab lain (buka pages/guru/guru.php)
  2. Klik tombol "Test Save" di bawah
  3. Lihat hasilnya di console browser (tekan F12)

Catatan: Jika error "Unauthorized", buka halaman guru terlebih dahulu untuk login.

Jika error "Siswa tidak ditemukan": Sesuaikan no_induk dan kelas di kode JavaScript dengan data real dari database Anda.
