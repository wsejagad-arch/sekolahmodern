🎯 HOW IT WORKS
═══════════════════════════════════════════════════════════════════════════════

BEFORE (Exposed URLs):
   Browser: http://localhost:8000/jurnal/pages/guru/nilai.php
   → Direct access to PHP file
   → Visible path in address bar

AFTER (Hidden URLs):
   Browser Request: /pages/guru/nilai OR /pages/guru/nilai.php
         ↓
   Apache Rewrite (root .htaccess):
         ↓ 
   Internal: pages/router.php?type=guru&page=nilai
         ↓
   pages/router.php:
         ├─ Validate: type=guru, page=nilai
         ├─ Check: User role (require_guru)
         ├─ Verify: File safe path & exists
         └─ Include: pages/guru/nilai.php
         ↓
   Browser: /jurnal/pages/guru/nilai (NO .php shown!)

🔐 SECURITY FEATURES IMPLEMENTED
═══════════════════════════════════════════════════════════════════════════════

✓ Input Validation
  - Type sanitized: guru|siswa|admin|public only
  - Page sanitized: a-z, 0-9, underscore, hyphen only
  - Prevents: SQL injection, path traversal, XSS

✓ Path Security
  - realpath() verification prevents ../../../ traversal
  - Checks: file exists, within allowed directory
  - Blocks: access to any file outside pages/

✓ Role-Based Access Control
  - require_guru()   → Only guru role
  - require_siswa()  → Only siswa role
  - require_admin()  → Only admin role
  - is_guru(), is_siswa(), is_admin() checks

✓ Session Security
  - HttpOnly cookies (prevent JS access)
  - Secure flag (HTTPS only)
  - SameSite=Lax (CSRF protection)

✓ File Access Control
  - .htaccess FilesMatch blocks .php direct access
  - All .php files in pages/ must go through router
  - No direct file execution possible
