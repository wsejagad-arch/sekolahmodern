🔍 TROUBLESHOOTING:

Jika masih 403:
1. Cek cPanel > Select PHP Version
2. Coba ganti .htaccess dengan versi PHP yang berbeda
3. Hubungi hosting: "aktifkan PHP untuk subdomain simanis"
4. Pastikan tidak ada .htaccess di atas folder yang blokir PHP

Jika database error:
1. Cek config.hosting.php
2. Verifikasi kredensial database
3. Cek database connection di cPanel
