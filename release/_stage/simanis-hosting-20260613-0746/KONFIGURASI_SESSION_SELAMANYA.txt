==============================================
KONFIGURASI SESSION LOGIN SELAMANYA
==============================================

PERUBAHAN YANG DILAKUKAN:
--------------------------
✅ Session lifetime diubah dari 0 (sampai browser ditutup)
   menjadi 315360000 detik (10 TAHUN)

✅ Session garbage collection lifetime diperpanjang
   ke 10 tahun untuk mencegah session dihapus otomatis

FILE YANG DIUPDATE:
-------------------
1. auth_helper.php   - Set session cookie params lifetime = 10 tahun
                     - Set session.gc_maxlifetime = 10 tahun

2. login_action.php  - Set session params sebelum login
                     - Ensure cookie lifetime = 10 tahun

CARA KERJA:
-----------
SEBELUM:
- Session lifetime = 0 (expire saat browser ditutup)
- User harus login ulang setiap kali tutup browser

SESUDAH:
- Session lifetime = 315360000 detik (10 tahun)
- Cookie session disimpan di browser selama 10 tahun
- User tetap login meskipun:
  ✅ Browser ditutup dan dibuka lagi
  ✅ Komputer restart
  ✅ Berhari-hari tidak akses
  ✅ Berminggu-minggu tidak akses

CATATAN KEAMANAN:
-----------------
⚠️ PENTING! Login "selamanya" memiliki risiko keamanan:

1. Jika komputer dipakai orang lain → mereka bisa akses akun Anda
2. Jika browser tidak dikunci → siapa saja bisa login
3. Jika cookie dicuri → akun bisa diakses tanpa password

REKOMENDASI KEAMANAN:
---------------------
✅ Gunakan fitur ini HANYA untuk:
   - Komputer pribadi yang aman
   - Browser yang terkunci dengan password
   - Jaringan yang aman

✅ SELALU logout manual jika:
   - Menggunakan komputer umum/shared
   - Menggunakan komputer kantor
   - Browser dipakai orang lain

CARA LOGOUT MANUAL:
-------------------
Klik menu "Keluar" atau akses: logout.php

TECHNICAL DETAILS:
------------------
session_set_cookie_params([
    'lifetime' => 315360000,  // 10 tahun dalam detik
    'path' => '/',
    'httponly' => true,       // Prevent XSS attacks
    'samesite' => 'Lax'       // CSRF protection
]);

ini_set('session.gc_maxlifetime', 315360000);

TESTING:
--------
1. Login ke sistem
2. Tutup browser
3. Buka browser lagi
4. Akses home.php
5. ✅ Masih tetap login (tidak perlu login ulang)

ROLLBACK (Jika ingin kembali ke normal):
-----------------------------------------
Ubah di auth_helper.php dan login_action.php:
'lifetime' => 0  (kembali ke expire saat browser ditutup)

atau

'lifetime' => 86400  (expire setelah 1 hari)
'lifetime' => 604800 (expire setelah 1 minggu)

CATATAN HOSTING:
----------------
Beberapa hosting provider mungkin membatasi session lifetime.
Jika tidak berfungsi di hosting, cek:
1. php.ini setting: session.gc_maxlifetime
2. Hosting control panel session settings
3. Server memory/storage untuk session files
