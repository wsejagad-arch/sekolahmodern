=== INSTRUKSI MANUAL SETUP DATABASE JURNAL ===

Karena ada masalah koneksi MySQL melalui PHP, silakan ikuti langkah berikut:

METODE 1: Menggunakan phpMyAdmin (REKOMENDASI)
-------------------------------------------------
1. Buka XAMPP Control Panel
2. Pastikan Apache dan MySQL sudah START (berwarna hijau)
3. Klik tombol "Admin" di sebelah MySQL untuk membuka phpMyAdmin
   ATAU buka browser: http://localhost/phpmyadmin

4. Login dengan:
   - Username: root
   - Password: (kosong/empty)

5. Di phpMyAdmin:
   - Klik tab "Databases"
   - Di kolom "Create database", ketik: jurnal
   - Klik "Create"

6. Setelah database jurnal dibuat:
   - Klik database "jurnal" di sidebar kiri
   - Klik tab "Import"
   - Klik "Choose File" dan pilih file: include/db_appsiswa.sql
   - Klik "Go" untuk import

METODE 2: Menggunakan Command Line MySQL
-----------------------------------------
1. Buka Command Prompt sebagai Administrator
2. Jalankan perintah:
   mysql -u root -p
   (password kosong, tekan Enter)

3. Di MySQL prompt:
   CREATE DATABASE jurnal;
   USE jurnal;
   SOURCE C:/xampp/htdocs/jurnal/include/db_appsiswa.sql;

SETELAH DATABASE BERHASIL DIBUAT:
=================================

1. Tambahkan data sample guru:
   INSERT INTO tbl_guru (no_induk, nama_guru, status_kepegawaian, foto, status)
   VALUES ('123456789', 'Ahmad Surya', 'PNS', '', 'Aktif');

2. Tambahkan data sample jadwal:
   INSERT INTO tbl_mapel_ampu (no_induk, nama_mapel, kelas, hari, jam_mulai, jam_selesai)
   VALUES ('123456789', 'Matematika', 'X-A', 'Senin', '07:00', '08:30');

3. Test koneksi:
   - Buka browser: http://localhost:8080/pages/guru/cetak_jurnal.php
   - Sistem akan redirect ke login
   - Login sebagai guru dengan NIP: 123456789

JIKA MASIH ADA MASALAH:
=======================
1. Restart XAMPP completely
2. Pastikan tidak ada program lain yang menggunakan port 3306
3. Cek Windows Firewall (nonaktifkan sementara untuk testing)

SETELAH SELESAI:
================
Database jurnal akan memiliki:
- Tabel: tbl_guru, tbl_mapel_ampu, tbl_materi, dll.
- Data sample untuk testing cetak jurnal
- Sistem cetak jurnal akan berfungsi normal
