4. REQUEST FLOW
═══════════════════════════════════════════════════════════════════════════════

BEFORE ❌:
   Browser Request: GET /pages/guru/nilai.php
         ↓
   Apache Server
         ↓ (direct execution)
   Execute: pages/guru/nilai.php
         ↓
   No security checks!
         ↓ Can be accessed by anyone
   Output: Page content


AFTER ✅:
   Browser Request: GET /pages/guru/nilai (or /pages/guru/nilai.php)
         ↓
   Apache .htaccess (RewriteRule)
         ↓
   Rewrite: pages/router.php?type=guru&page=nilai
         ↓
   pages/.htaccess: Blocks direct .php access
         ↓
   Router validates:
   ├─ Input: type=guru, page=nilai (sanitized)
   ├─ Security: realpath() prevents path traversal
   ├─ Role: require_guru() checks user is guru
   ├─ File: exists & within allowed directory
   └─ Success: include pages/guru/nilai.php
         ↓
   Output: Page content (only if authorized)

═══════════════════════════════════════════════════════════════════════════════
6. .HTACCESS CHANGES
═══════════════════════════════════════════════════════════════════════════════

BEFORE ❌:
   (Root .htaccess had no pages/* routing)

AFTER ✅ (Root .htaccess):
   # Route pages/* to router.php
   RewriteCond %{REQUEST_FILENAME} !-f
   RewriteCond %{REQUEST_FILENAME} !-d
   RewriteRule ^pages/guru/([a-zA-Z0-9_-]+)(?:\.php)?/?$ pages/router.php?type=guru&page=$1 [L,QSA]
   RewriteRule ^pages/siswa/([a-zA-Z0-9_-]+)(?:\.php)?/?$ pages/router.php?type=siswa&page=$1 [L,QSA]
   RewriteRule ^pages/admin/([a-zA-Z0-9_-]+)(?:\.php)?/?$ pages/router.php?type=admin&page=$1 [L,QSA]

BEFORE ❌ (pages/.htaccess):
   (Minimal blocking rules)

AFTER ✅ (pages/.htaccess):
   # Deny direct access to PHP files
   <FilesMatch "\.php$">
       Require all denied
   </FilesMatch>
   
   # All requests must go through parent .htaccess to router.php

7. SECURITY COMPARISON
═══════════════════════════════════════════════════════════════════════════════

BEFORE ❌:
   - No input validation on direct paths
   - Anyone can guess page names: pages/guru/nilai.php
   - No role checking (guru pages accessible by siswa)
   - Direct file inclusion: require() $_GET values
   - Path traversal possible: ../../../etc/passwd
   - No session verification

AFTER ✅:
   - Input sanitized: regex validation [a-z0-9_-]
   - Path guessing still possible but routed through router
   - Role checking: require_guru(), require_siswa(), require_admin()
   - Centralized router: single security point
   - Path traversal blocked: realpath() verification
   - Session verified: require_login() before access
   - File existence checked: verify before include
   - CSRF protection ready: generate_csrf_token() available
