INSTRUKSI PERBAIKAN SIDEBAR & CSS DI CONSOLE
==============================================

MASALAH YANG DITEMUKAN:
-----------------------
1. Menu sidebar tidak bisa diklik
2. CSS content muncul di browser console
3. Error: "$(...).collapse is not a function"

PENYEBAB:
---------
1. Ada baris kosong di awal file mycss.css yang menyebabkan parsing error
2. Manual event handler di footer.php CONFLICT dengan Bootstrap native
3. sb-admin-2.min.js sudah handle collapse otomatis, tidak perlu manual handler

SOLUSI YANG SUDAH DITERAPKAN:
------------------------------
1. ✅ Hapus baris kosong di awal file css/mycss.css
2. ✅ Hapus manual collapse handler dari footer.php
3. ✅ Biarkan Bootstrap native handle semua collapse
4. ✅ Update sidebar.php dengan URL yang benar

FILE YANG DIUPDATE:
-------------------
1. css/mycss.css         - Hapus baris kosong di awal file
2. footer.php            - Hapus manual collapse handler (PENTING!)
3. sidebar.php           - Menu sudah menggunakan home.php?page=
4. home.php              - Struktur HTML sudah diperbaiki

LANGKAH UPLOAD KE HOSTING:
---------------------------
1. Upload file berikut ke hosting:
   - css/mycss.css (PENTING!)
   - footer.php (PENTING! - ini yang menyebabkan error collapse)
   - home.php
   - sidebar.php

2. Setelah upload, lakukan HARD REFRESH di browser:
   - Chrome/Edge: Ctrl + Shift + R atau Ctrl + F5
   - Firefox: Ctrl + F5
   - Safari: Cmd + Shift + R

3. Clear browser cache jika masih ada masalah:
   - Buka DevTools (F12)
   - Klik kanan tombol Refresh
   - Pilih "Empty Cache and Hard Reload"

TEST SETELAH UPLOAD:
--------------------
1. Buka halaman home.php
2. Buka Browser Console (F12)
3. Klik menu "Data Guru" di sidebar - harus expand/collapse
4. TIDAK boleh ada error "collapse is not a function"
5. Cek console - TIDAK boleh ada CSS content

FILE TEST YANG TERSEDIA:
------------------------
1. test_sidebar_simple.php       - Test dengan NATIVE Bootstrap (RECOMMENDED)
2. test_sidebar_diagnosis.php    - Test dengan error handling
3. test_clean_sidebar.php        - Test tanpa mycss.css

Jika masih ada masalah setelah upload, jalankan:
http://localhost/jurnal/test_sidebar_simple.php

CATATAN PENTING:
----------------
- File footer.php SANGAT PENTING untuk diupload karena mengandung fix
- JANGAN tambah manual collapse handler - Bootstrap sudah handle otomatis
- sb-admin-2.min.js sudah mengaktifkan semua data-toggle="collapse"
- File css/mycss.css harus tanpa baris kosong di awal
- Clear browser cache WAJIB dilakukan setelah upload

PENJELASAN TEKNIS:
------------------
Error "$(...).collapse is not a function" terjadi karena:
1. Manual event handler dijalankan sebelum Bootstrap selesai load
2. Double event binding menyebabkan conflict
3. sb-admin-2.min.js sudah otomatis handle collapse via data attributes

Solusinya: HAPUS manual handler, biarkan Bootstrap native bekerja.
