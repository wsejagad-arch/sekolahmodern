CARA UPLOAD .user.ini KE HOSTING
===============================

File asli bernama .user.ini (diawali titik) sehingga sering TIDAK TERLIHAT
di Windows dan kadang tidak ikut ter-extract dari ZIP.

PILIHAN A — Buat langsung di cPanel (paling mudah)
---------------------------------------------------
1. Login cPanel > File Manager
2. Masuk folder: public_html/simanis
3. Klik + File (New File)
4. Nama file: .user.ini
5. Isi file (copy tempel):

   engine = On

6. Save

PILIHAN B — Upload dari komputer
--------------------------------
1. Buka folder di komputer:
   C:\xampp\htdocs\jurnal\release\

2. Gunakan file: user-ini-UPLOAD-INI.txt
   (atau: C:\xampp\htdocs\jurnal\user.ini)

3. Upload ke public_html/simanis

4. Di cPanel File Manager, RENAME menjadi: .user.ini

PILIHAN C — Tampilkan file tersembunyi di Windows
--------------------------------------------------
1. File Explorer > View > Show > Hidden items
2. Buka: C:\xampp\htdocs\jurnal\
3. Cari file: .user.ini

CATATAN
-------
PHP Anda sudah jalan (8.1.34), jadi .user.ini TIDAK WAJIB.
Yang lebih penting: config.hosting.php dan koneksi database.
