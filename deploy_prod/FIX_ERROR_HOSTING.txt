# FIX ERROR: Syntax Error & index.js undefined

## Error Yang Muncul:
1. `index.js:3 Uncaught ReferenceError: exports is not defined`
2. `home.php?page=pengumuman:692 Uncaught SyntaxError: Unexpected token '}'`

## Solusi:

### 1. Hapus file index.js di hosting (jika ada)
   - File ini corrupt atau tidak diperlukan
   - Di cPanel File Manager, cari file `index.js` di folder `js/` atau root
   - Hapus file tersebut

### 2. Upload ulang home.php yang sudah diperbaiki
   File source: `C:\xampp\htdocs\jurnal\deploy_prod\home.php`
   Upload ke: `sijurnal.sma1sumber.sch.id/home.php`
   
   **PENTING:** Overwrite file lama, jangan rename!

### 3. Upload file-file ini juga (jika belum):
   - `footer.php` → overwrite yang lama
   - `header.php` → overwrite yang lama
   - `sidebar.php` → overwrite yang lama
   - `pages/admin/pengumuman.php` → pastikan sudah ada!

### 4. Clear Cache Browser
   - Tekan Ctrl + Shift + Delete
   - Pilih "Cached images and files"
   - Klik Clear
   - ATAU buka Incognito window

### 5. Test
   - Buka: https://sijurnal.sma1sumber.sch.id/test_pengumuman.php
   - Harus muncul: "pages/admin/pengumuman.php exists: YES"
   - Buka: https://sijurnal.sma1sumber.sch.id/home.php?page=pengumuman
   - Halaman harus muncul tanpa error
